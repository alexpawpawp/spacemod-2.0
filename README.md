# Космический мод — открытый космос + агрессивные мобы

## Открытый космос
1. Ракета + топливо
2. Shift+ПКМ → выбрать **«Открытый космос»**
3. ПКМ → телепорт
4. Вокруг — **планеты в виде цветных кубов** (Меркурий…Плутон, Луна, Европа)
5. ПКМ по кубу — название и размер
6. Возвратная ракета — обратно на Землю

## Агрессивные мобы
- Пылевой охотник
- Вольфийский громоход
- Лавовый панцирник
- **Космический рейдер** (новый)
- **Охотник пустоты** (новый)
- Спавнятся в открытом космосе и на Марсе

## Планеты-кубы
Цветные кубы разного размера в измерении open_space.
Можно подлетать (лететь в креативе / элитрах) и рассматривать.

## Остальное
Ракеты, измерения, миссии, колония, орбитальная карта, камера зонда, чёрная дыра — как раньше.
